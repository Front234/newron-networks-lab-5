## Лабораторная работа "Реккурентные и одномерные сверточные нейронные сети"

## Структура репозитория

- `lab5Lite.ipynb` –  ноутбук для задания Lite: исследование влияния параметров токенизации и разбиения текста на качество классификации авторов. Обучение выбранной RNN/CNN модели на датасетах с разными VOCAB_SIZE и (WIN_SIZE, WIN_HOP). Сравнение точности и оформление результатов в таблице.
- `lab5Pro.ipynb` – ноутбук для задания Pro: построение модели для классификации 10 заболеваний по симптомам. Модель с минимум 2 сверточными слоями и обязательными слоями подвыборки, нормализации и регуляризации. Обучение и достижение корректной классификации ≥6 классов.
- `lab5Ultra_Pro.ipynb` – ноутбук для задания Ultra Pro: обучение модели для определения авторства текстов 20 русских писателей. Подготовка корпуса, обучение классификатора и проверка на собственном тексте с интерпретацией результата.
- `lab5Pytorch.ipynb` – ноутбук для задания Lite: исследование влияния параметров токенизации и разбиения текста на качество классификации авторов. Обучение выбранной RNN/CNN модели на датасетах с разными VOCAB_SIZE и (WIN_SIZE, WIN_HOP). Сравнение точности и оформление результатов в таблице. Выполнено с использованием Pytorch

## Требования

Для запуска ноутбуков рекомендуется использовать **Google Colab**. Все необходимые библиотеки предустановлены в Colab.
